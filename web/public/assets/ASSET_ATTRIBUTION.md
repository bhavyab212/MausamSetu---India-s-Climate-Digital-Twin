# Phase 4 visual assets

- `cauvery-landscape.webp`: downloaded from Unsplash photo `qjFjOfboWOA` by R.S. SAGAR, used as a blurred dashboard backdrop.
- `map/south-india-overview.svg`: generated locally from geoBoundaries India ADM1 data (CC BY 2.5 IN; source: DataMeet India / Election Commission of India), with state geometry simplified for the dashboard map.
- `map/cauvery-basemap.webp`: locally stitched OpenStreetMap tiles from `tile.openstreetmap.org`, downloaded for development visual verification; © OpenStreetMap contributors.
